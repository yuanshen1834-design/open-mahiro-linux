## 二、安装到虚拟机（VMware Workstation / Player）

1. 新建虚拟机 → 选择「安装程序光盘映像文件(iso)」→ 选中本 ISO；
2. 客户机操作系统选 **Debian 12.x / 13.x 64 位**（没有则选「其他 Linux 5.x 内核 64 位」）；
3. 磁盘 ≥ 20 GB，内存 ≥ 2 GB；
4. 网络类型选 **NAT** —— 安装过程需要联网下载软件包；
5. 开机后菜单第一项 **「安装 open绪山真寻Linux（自动，推荐）」** 会在 15 秒后自动开始，也可按回车立即开始；
6. 之后全自动：分区 → 装系统 → 装桌面 → 配中文 → 配 Wine → 重启。

安装时长约 10–40 分钟（需下载 1.5–2 GB 软件包）。

---

## 三、安装到物理硬盘 / U 盘

1. **制作启动盘**：Rufus（写入模式选 **DD 模式**）或 balenaEtcher，U 盘 ≥ 2 GB；
2. 进入 BIOS/UEFI，**关闭 Secure Boot**（本镜像 GRUB 未签名）；
3. 从 U 盘启动，选第一项，自动安装到整块硬盘。

> ⚠️ **自动安装会清空目标磁盘的全部分区数据。**
> 需要与 Windows 共存时，请选「图形界面安装（手动）」自行分区。

## 五、运行 Windows 软件（Wine 兼容层）

| 方式 | 操作 |
| --- | --- |
| **直接双击** | 文件管理器里双击 `.exe` / `.msi`，自动用 Wine 运行 |
| **菜单入口** | 应用菜单 → **安装 Windows 软件** → 选择 exe |
| **命令行** | `wine 程序.exe` |
| **增强配置** | `winetricks`（装 .NET、VC 运行库、中文字体等） |

首次运行会自动创建 `~/.wine` 前缀（约 1 分钟）。

> **限制**：Wine 不是真正的 Windows。带内核级反作弊的网游无法运行；微信、QQ、钉钉等新版国产软件兼容性差；复杂安装包可能失败。需要完整 Windows 环境时，建议在虚拟机里装真 Windows。

## 六、deb 软件包管理（完整 Debian 体系）

```bash
sudo apt update            # 更新软件索引
sudo apt install 包名       # 安装软件
sudo apt remove 包名        # 卸载软件
sudo apt full-upgrade      # 升级整个系统
sudo dpkg -i 文件名.deb     # 安装本地 deb 包
sudo apt -f install        # 修复依赖
```

**图形界面**：Synaptic 软件包管理器（搜索/安装/卸载/依赖）、GDebi（双击 `.deb` 安装）。

软件源默认指向清华 TUNA 镜像，配置在 `/etc/apt/sources.list.d/`。

## 八、常见问题

**Q：安装到一半提示找不到软件包 / 下载失败？**
A：检查网络，安装过程需访问 `mirrors.tuna.tsinghua.edu.cn`。网络受限时可改用「图形界面安装（手动）」并手动选择镜像源。

**Q：开机直接进 GRUB 命令行？**
A：通常是 Secure Boot 未关闭，或 U 盘写入时未使用 DD 模式。

**Q：忘记密码？**
A：GRUB 菜单按 `e`，在 `linux` 行末尾加 `init=/bin/bash`，进入后 `mount -o remount,rw /`，再 `passwd` 修改。

**Q：能装到 ARM 设备 / 树莓派吗？**
A：不能，本镜像仅支持 x86_64（Intel / AMD）。
