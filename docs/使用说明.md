## 二、磁盘分区：由你选择（支持双系统）

安装到「分区磁盘」步骤时会列出方案：

| 方案 | 用途 | 影响 |
| --- | --- | --- |
| **向导 - 使用整个磁盘** | 单系统 | **清空整块硬盘** |
| **向导 - 使用最大的连续空闲空间** | 双系统 | 只在空闲空间安装，Windows 不受影响 |
| **手动** | 高级用户 | 自己划 `/`、swap、EFI |

> ⚠️ 只有选「使用整个磁盘」才会清空整盘。
> 装双系统请先在 Windows 里压缩出未分配空间，再选「使用最大的连续空闲空间」。
> GRUB 会自动探测已存在的 Windows，开机菜单同时列出两个系统。

## 三、启动菜单（英文，避免乱码）

```
Install open mahiro Linux              ← 默认（回车）
Text mode install
Install without preseed (fully manual)
Rescue mode
```

| 选项 | 说明 |
| --- | --- |
| `Install open mahiro Linux` | 推荐。中文界面；语言/时区/软件源/软件包自动配置；**分区与账号由你填写** |
| `Text mode install` | 纯文本界面，显卡不兼容时使用 |
| `Install without preseed (fully manual)` | 完全手动，装出纯 Debian，无中文环境与预装软件 |
| `Rescue mode` | 救援模式，修复已装好的系统 |

> 菜单用英文是刻意的：GRUB 阶段没有中文字体，中文会显示为方块或乱码。安装界面与装好的系统仍是中文。

## 四、安装到虚拟机（VMware Workstation / Player）

1. 新建虚拟机 → 「安装程序光盘映像文件(iso)」→ 选中本 ISO；
2. 客户机系统选 **Debian 12.x / 13.x 64 位**（没有则选「其他 Linux 5.x 内核 64 位」）；
3. 磁盘 ≥ 20 GB，内存 ≥ 2 GB；
4. 网络选 **NAT** —— 安装需要联网下载软件包；
5. 开机直接回车，进入中文安装界面；
6. 中途会询问：主机名、域名、**root 密码**、**用户名与密码**、**分区方案**、软件源（已自动），按提示填写；
7. 安装完成后首次启动，用**你自己设置的账号**登录。

安装时长约 10–40 分钟（需下载 1.5–2 GB 软件包）。

---

## 五、安装到物理硬盘 / U 盘

1. **制作启动盘**：Rufus（**DD 模式**）或 balenaEtcher，U 盘 ≥ 2 GB；
2. BIOS/UEFI 中**关闭 Secure Boot**（本镜像 GRUB 未签名）；
3. U 盘启动 → 选第一项 → 按提示安装；
4. 双系统：先在 Windows 磁盘管理压缩出未分配空间，安装时选「使用最大的连续空闲空间」。

## 七、运行 Windows 软件（Wine 兼容层）

| 方式 | 操作 |
| --- | --- |
| **直接双击** | 双击 `.exe` / `.msi` 自动用 Wine 运行 |
| **菜单入口** | 应用菜单 → **安装 Windows 软件** → 选择 exe |
| **命令行** | `wine 程序.exe` |
| **增强配置** | `winetricks`（.NET、VC 运行库、中文字体等） |

首次运行创建 `~/.wine`（约 1 分钟）。

> Wine 不是真正的 Windows：带反作弊的网游无法运行，微信/QQ/钉钉等新版国产软件兼容性差。

## 十、常见问题

**Q：安装到一半提示找不到软件包 / 下载失败？**
A：检查网络（需访问 `mirrors.tuna.tsinghua.edu.cn`）。网络受限时可改用 `Install without preseed` 自行配置源。

**Q：开机直接进 GRUB 命令行？**
A：Secure Boot 未关闭，或 U 盘写入未用 DD 模式。

**Q：忘记密码？**
A：GRUB 菜单按 `e`，`linux` 行末尾加 `init=/bin/bash`，进入后 `mount -o remount,rw /`，再 `passwd`。

**Q：能装到 ARM / 树莓派吗？**
A：不能，仅支持 x86_64。

**Q：菜单为什么是英文？**
A：GRUB 阶段无中文字体，中文会乱码；安装界面和系统本身仍是中文。
