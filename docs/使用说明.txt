  一、安装时要你自己填写的信息    ← 重点
================================================================

  本发行版没有内置的默认账号，安装过程中会要求你现场设置：

  >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
  >>>                                                  >>>
  >>>    用  户  名 ：  由 你 自 己 输 入                >>>
  >>>    密        码 ：  由 你 自 己 输 入                >>>
  >>>                                                  >>>
  >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

  · root 密码：同一环节设置（root 账户本身默认禁用登录，
    日常用 sudo 提权）
  · 普通用户：全名、用户名、密码三项都由你决定
  · 建议：密码记牢；装好之后随时可用 passwd 修改

  【提示】本文档是纯文本，无法显示真正的字体加粗，
          所以关键项都用 >>> 【】 ★ 等符号框出来，
          方便一眼看到。


================================================================
  二、磁盘分区：由你选择（支持双系统）
================================================================

  安装进行到「分区磁盘」这一步时，会列出分区方案，常见选项：

    向导 - 使用整个磁盘
        → 单系统。会清空整块硬盘，请确认没有重要数据。

    向导 - 使用最大的连续空闲空间
        → 双系统。只在空闲空间里装，Windows 与数据不受影响。

    手动
        → 高级用户。自己划 /、swap、EFI 分区。

  【警告】只有选「使用整个磁盘」才会清空整盘。
          想装双系统，请先给硬盘留出未分配空间，
          再选「使用最大的连续空闲空间」。

  引导程序（GRUB）会自动探测已有的 Windows，安装后开机菜单
  里同时出现两个系统。


================================================================
  三、启动菜单（已改为英文，避免乱码）
================================================================

  光盘/U 盘启动后看到的是：

    Install open mahiro Linux                 ← 默认（回车）
    Text mode install
    Install without preseed (fully manual)
    Rescue mode

  各选项含义：

    Install open mahiro Linux
        推荐。中文界面安装；语言、时区、软件源、要装的软件包
        自动准备好；分区和账号由你填。

    Text mode install
        同样的流程，纯文本界面（显卡不兼容时用）。

    Install without preseed (fully manual)
        完全手动，不带任何预置，装出来是「纯 Debian」，
        没有中文环境和预装软件。适合排查问题。

    Rescue mode
        救援模式，用于修复已装好的系统。

  菜单为英文是刻意的：GRUB 引导阶段没有中文字体，中文会显示
  成方块或乱码。安装界面本身依然是中文。


================================================================
  四、安装到虚拟机（VMware Workstation / Player）
================================================================

  1. 新建虚拟机，选「安装程序光盘映像文件(iso)」，选中本 ISO；
  2. 客户机系统选 Debian 12.x / 13.x 64 位
     （没有就选「其他 Linux 5.x 内核 64 位」）；
  3. 磁盘不少于 20 GB，内存不少于 2 GB；
  4. 网络选 NAT —— 安装需要联网下载软件包；
  5. 开机后直接回车，进入中文安装界面；
  6. 中途会停下来问你：语言（已自动）、主机名、域名、
     root 密码、用户名密码、分区方案、软件源（已自动）等，
     按提示填写即可；
  7. 安装完成后首次启动，用你自己设置的账号登录。

  安装时长：视网速约 10 ~ 40 分钟（需下载 1.5 ~ 2 GB 软件包）。


================================================================
  五、安装到物理硬盘 / U 盘
================================================================

  1. 制作启动盘：
     - Rufus（https://rufus.ie），写入模式选「DD 模式」；
     - 或 balenaEtcher（https://etcher.balena.io/）；
     - U 盘容量 2 GB 以上。
  2. 进入主板 BIOS/UEFI，关闭 Secure Boot（本镜像 GRUB 未签名）；
  3. 从 U 盘启动 → 选第一项 → 按提示安装；
  4. 装双系统时，先在 Windows 磁盘管理里压缩出未分配空间，
     安装时选「使用最大的连续空闲空间」。

================================================================
  七、运行 Windows 软件（Wine 兼容层）
================================================================

  1) 直接双击
     文件管理器里双击 .exe / .msi，自动用 Wine 打开。

  2) 菜单入口
     应用菜单 → 「安装 Windows 软件」→ 选择 exe → 按提示安装。

  3) 命令行
     wine 程序.exe

  增强配置：winetricks（可装 .NET、VC 运行库、中文字体等）。

  首次运行会自动创建 ~/.wine 目录（约 1 分钟）。

  【限制】Wine 不是真正的 Windows：
     · 带内核级反作弊的网游无法运行；
     · 微信、QQ、钉钉等新版国产软件兼容性差；
     · 复杂安装包可能失败。


================================================================
  八、deb 软件包管理（完整 Debian 体系）
================================================================

     sudo apt update                更新软件索引
     sudo apt install 包名           安装软件
     sudo apt remove 包名            卸载软件
     sudo apt full-upgrade          升级整个系统
     sudo dpkg -i 文件名.deb         安装本地 deb 包
     sudo apt -f install            修复依赖

  图形界面：Synaptic 软件包管理器、GDebi（双击 .deb 安装）。

  软件源默认指向清华 TUNA 镜像，配置在 /etc/apt/sources.list.d/。

================================================================
  十、常见问题
================================================================

  Q: 安装到一半提示找不到软件包 / 下载失败？
  A: 检查网络，安装过程需访问 mirrors.tuna.tsinghua.edu.cn。
     网络受限时可改用「Install without preseed」，自行配置源。

  Q: 开机直接进 GRUB 命令行？
  A: 通常是 Secure Boot 未关闭，或 U 盘写入时未用 DD 模式。

  Q: 忘记密码怎么办？
  A: 启动时在 GRUB 菜单按 e，在 linux 行末尾加 init=/bin/bash，
     进入后执行 mount -o remount,rw / 再 passwd 修改。

  Q: 能装到 ARM 设备 / 树莓派吗？
  A: 不能，本镜像仅支持 x86_64（Intel / AMD）。

  Q: 菜单为什么是英文？
  A: GRUB 阶段没有中文字体。安装界面、装好后的系统都是中文。
